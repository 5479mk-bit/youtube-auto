# 숫자가 말해준다 — 공공데이터 다큐 쇼츠 자동화

공공데이터에서 "시청자가 자기 얘기로 느끼는 통계"를 찾아, 30~40초짜리 세로 쇼츠 **1부/2부**를
자동으로 만든다. 1부는 숫자를 던지고 질문을 남기고, 2부는 그 이유를 데이터로 답한다.
완성된 영상과 후킹 제목 후보는 **텔레그램으로 먼저 전송되고, 사람이 승인해야 유튜브에 올라간다.**

[MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo)의 단계 분리 구조를
참고했지만, 스톡 영상을 잇는 대신 **실사 사진 Ken-Burns + 데이터 차트 + 내레이션**이라는
다큐 구성을 쓴다.

## 왜 이 방식인가

- 유튜브는 2026년 최우선 과제로 저품질 AI 콘텐츠('AI 슬롭') 정리를 내세웠다. 출처가 검증되는
  정부 데이터 기반 콘텐츠는 그 반대편에 선다.
- 한국 쇼츠 시장에 공공데이터 기반 데이터 저널리즘 채널이 거의 없다.
- 댓글의 "우리 동네는요?"가 다음 회차 소재가 되는 선순환이 만들어진다.

## 동작 흐름

```
공공데이터 수집 → 이야깃거리 후보 추출 → 감정 훅 스코어링으로 주제 1건 선정
   → 1부/2부 대본 → 사진 수집 + 차트 렌더 → TTS 내레이션 → 자막
   → 컷 배치(카메라 무빙) → mp4 2편 → 텔레그램 검수 → 승인 시 유튜브 업로드
```

## 영상 구성 규칙

세로 1080×1920, 30fps.

| 구간 | 화면 | 카메라 |
|---|---|---|
| 훅 (0~3초) | 핵심 숫자 하나만 초대형 타이포, 배경 흑백→컬러 | 느린 push-in |
| 문제 제기 | 관련 장소 실사 사진 | pan, 컷당 2.5~3초 |
| 데이터 전개 | 사진 + 차트가 내레이션에 맞춰 한 항목씩 공개 | push-in / pull-out 교차 |
| 클리프행어 (1부 끝) | "2부에서 계속" | freeze |

- **안전 영역**: 상단 25%와 하단 25%는 유튜브 UI가 덮으므로 핵심 정보를 넣지 않는다.
- **무빙 교차**: 연속한 컷은 절대 같은 방향 무빙을 쓰지 않는다.
- **무음 대응**: 모든 내레이션은 자막으로 번인되고, 핵심 숫자는 색으로 강조된다.
- **차트 동기화**: 내레이션이 부르는 항목은 반드시 그 시점에 차트에 떠 있다.

## 설치

```bash
pip install -r requirements.txt
cp .env.example .env    # 키를 채운다
```

한국어 자막 폰트(Noto Sans KR)는 첫 실행 때 `resource/fonts/`에 자동으로 내려받는다.
배경음악을 쓰려면 `resource/bgm/`에 무료 라이선스 음원을 넣는다(없으면 내레이션만 나간다).

## 키 발급

| 키 | 발급처 | 없으면 |
|---|---|---|
| `DATA_GO_KR_SERVICE_KEY` | [공공데이터포털](https://www.data.go.kr) 활용신청 | 번들 샘플 데이터로 동작하고, 업로드는 차단된다 |
| `GEMINI_API_KEY` | Google AI Studio 무료 티어 | 데이터만으로 구성한 템플릿 대본을 쓴다 |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | @BotFather | 검수를 건너뛰고 업로드하지 않는다 |
| `YOUTUBE_CLIENT_SECRET_FILE` | Google Cloud Console OAuth 데스크톱 클라이언트 | 업로드 단계만 실패한다 |

TTS(edge-tts)는 키가 필요 없다. 프록시 뒤에서는 `HTTPS_PROXY`를 읽어 자동으로 사용한다.

## 사용법

```bash
python main.py topics            # 주제 후보 확인만
python main.py run --dry-run     # 주제·대본까지만 (영상 렌더 없음)
python main.py run               # mp4 2편 생성
python main.py run --review      # 생성 후 텔레그램 검수 → 승인 시 유튜브 업로드
```

산출물은 `output/<타임스탬프>/`에 남는다. `part1.mp4`, `part2.mp4`, 썸네일, `script.json`,
`.srt`, `result.json`.

## 안전장치

- **샘플 데이터 차단**: 서비스키가 없어 번들 픽스처로 만든 영상은 화면에 "샘플 데이터 · 실제
  통계 아님"이 표시되고, 승인하더라도 업로드가 거부된다. 가짜 숫자가 정부 통계로 둔갑하지
  않게 하기 위한 장치다.
- **기본 비공개 업로드**: `config.yaml`의 `publish.privacy_status`가 `private`이다. 공개
  전환은 사람이 확인한 뒤에 한다.
- **중복 방지**: 이미 다룬 주제는 `state.sqlite3`에 기록되어 다시 선정되지 않는다.
- **이미지 라이선스 필터**: 위키미디어 커먼즈 결과 중 허용 라이선스만 내려받는다.

## 데이터셋 추가하기

`src/datasource/datasets/`에 어댑터를 하나 추가하고 `ADAPTERS`에 등록하면 된다. 어댑터는
원천 API의 생김새를 숨기고 `StoryCandidate` 리스트만 돌려준다. 각 후보는 네 가지 축
(`personal_relevance`, `surprise`, `magnitude`, `freshness`)으로 점수가 매겨진다.

포함된 어댑터의 엔드포인트 경로는 각 파일 상단 주석의 데이터셋 페이지에서 활용신청 후
상세 문서에 맞춰 조정해야 할 수 있다.
